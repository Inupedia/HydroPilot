# Expected release assets

For a tag such as `v0.2.0`, the release workflow should attach artifacts for:

- macOS Apple Silicon: DMG and ZIP;
- macOS Intel: DMG and ZIP;
- Windows x64: NSIS EXE and ZIP;
- Linux x64: AppImage and TAR.GZ.

Exact filenames are generated by electron-builder and include the package version and, where applicable, architecture.
