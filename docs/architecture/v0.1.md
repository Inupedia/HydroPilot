# HydroPilot v0.1 Architecture

HydroPilot v0.1 is a public-data water-network digital twin demonstrator. It separates geometry from directed hydraulic topology so that visual scenes can answer downstream-impact questions before any heavy hydraulic model is introduced.

## Runtime path

1. `data/demo/sacramento_v0_1.json` provides a compact public-data-derived fixture.
2. `hydro_object` stores river reaches, reservoirs, dams, gauges, and control points.
3. `hydro_relation` stores water-network and engineering relations such as `FLOWS_TO`, `DISCHARGES_TO`, and `CONTROLS`.
4. The API serves objects, downstream topology, and release-routing scenarios.
5. The core package computes deterministic 0D reservoir mass balance and 1D Muskingum routing.
6. The web app renders a map-first water-network scene and timeline.
7. The SFINCS adapter remains isolated for manual/nightly regression.

## Limitations

This release is not operational flood-control or reservoir-dispatch decision support. It does not provide calibrated hydraulic predictions, official warning information, or optimized operating recommendations.
